# HELLO - 모던 크리에이티브 웹 애플리케이션 🚀

이 프로젝트는 반응형 3D 인터랙티브 디자인과 현대적인 UI/UX 요소가 적용된 싱글 페이지 웹 애플리케이션(SPA) 프로젝트입니다.

---

## 📁 프로젝트 파일 구조

* **`hello.html`**: 메인 웹 애플리케이션 페이지. 3D 인터랙티브 배경, 다크/라이트 모드 지원, 마우스 위치에 반응하는 커서 스토커(Cursor Stalker), 그리고 세련된 글래스모피즘(Glassmorphism) 카드 UI가 적용되어 있습니다.
* **`AWS.TXT`**: 프로젝트 배포를 위한 AWS 클라우드 및 가상 서버(EC2 등)의 접속 정보 파일입니다.
* **`.gitignore`**: Git 버전 관리 시 불필요한 시스템 임시 파일이나 빌드 결과물 등을 제외하기 위한 설정 파일입니다.

---

## 💻 실행 및 개발 방법

### 로컬 실행
1. `hello.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 열 수 있습니다.
2. 마우스 인터랙션이나 외부 리소스의 원활한 로드를 위해 VS Code의 **Live Server** 익스텐션 등을 사용하여 로컬 웹 서버 환경에서 여는 것을 권장합니다.
